

# ANRE Quiz

Aplicație de pregătire pentru examenul ANRE, concepută pentru exersarea și consolidarea cunoștințelor necesare obținerii autorizației.

## Materii disponibile

Aplicația include întrebări din trei domenii:

- **Electrotehnică**
- **Norme tehnice**
- **Legislație**

## Funcționalități

- Parcurgerea întrebărilor pe materii sau în modul de practică.
- Teste cu număr configurabil de întrebări.
- Întrebări cu unul sau mai multe răspunsuri corecte.
- Feedback pentru răspunsurile selectate.
- Urmărirea progresului pentru fiecare materie.
- Reluarea întrebărilor după parcurgerea integrală a unei materii.

## Utilizare

Aplicația poate fi accesată din browser, atât pe desktop, cât și pe dispozitive mobile.

Pentru o experiență optimă pe telefon, aplicația poate fi adăugată pe ecranul principal și utilizată într-un format similar unei aplicații native.
