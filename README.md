# ANRE Quiz – versiune iPhone/PWA

Această versiune este optimizată pentru iPhone și poate fi adăugată pe ecranul principal după publicarea pe HTTPS.

Chestionarul mixt acceptă seturi prestabilite sau un număr personalizat de întrebări. Toate întrebările cer apăsarea butonului „Verifică răspunsul” înainte de feedback. La întrebările cu răspuns multiplu, răspunsul este corect numai dacă sunt selectate toate variantele corecte și nicio variantă greșită.

Publicare: încărcați toate fișierele din acest folder în root-ul repository-ului GitHub Pages. Deschideți linkul în Safari pe iPhone, Partajare → Adăugați la ecranul principal.
Progresul se salvează local și nu se sincronizează automat între dispozitive.


În chestionarele de antrenament rapid, toate întrebările permit selectarea uneia sau mai multor variante, fără eticheta „Răspuns simplu/multiplu”. În zona de învățare pe materii, tipul întrebării rămâne afișat ca înainte.


Scheme electrotehnice: imaginile furnizate sunt incluse pentru întrebările 8, 25–27 (variante vizuale), 31, 34, 40–41, 169–170 și 174–175. Întrebările 25–27 sunt marcate cu cheie neconfirmată: schemele sunt afișate, dar aplicația nu pretinde că știe varianta corectă până la validarea răspunsului.
